# Best-Practice Sources

This process borrows from widely used product, engineering, and operating-model practices.

## Product Operating Model

- SVPG's product operating model: empowered product teams should own both discovery and delivery outcomes, with PMs strongly focused on value and viability.
- Product discovery and delivery should be connected, not treated as separate handoff factories.

## Decision and Responsibility Models

- DACI is useful for decisions where a clear driver, approver, contributors, and informed audience reduce ambiguity.
- RACI is useful for task or deliverable responsibility where accountable, responsible, consulted, and informed roles need to be explicit.

## Repository Governance

- CODEOWNERS should identify owners who are automatically requested for review when protected areas change.
- Pull request templates reduce review ambiguity by making authors state what changed, why, impact, risks, and rollout notes.
- Branch protection should prevent accidental changes to the source of truth.

## Local Adaptation

These practices should be adapted to the company's size, culture, and operating reality. The standard is not maximum ceremony. The standard is enough structure to make ownership, readiness, communication, and decision-making reliable.
