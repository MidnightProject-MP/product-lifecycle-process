# Project Status Executive Dashboard

The executive dashboard is the source for planned project status updates and weekly digest communication.

It should give leaders a compact view of:

- What the project is.
- Who owns it.
- Where it is in the lifecycle.
- How much exposure exists.
- Whether the work is healthy.
- How confident the owner is.
- What risk matters most.
- What major gate comes next.
- Who or what the rollout is targeting.

## Dashboard Fields

| Section | Field | Purpose | Owner |
| --- | --- | --- | --- |
| Project Info | Project | Names the project or initiative. | Lead PM |
| Project Info | Lead PM | Names the person driving project communication and follow-through. | Lead PM |
| Project Info | Owner | Names the accountable business or phase owner. | Lead PM |
| Current Phase | Current Phase | Shows where the project is in the lifecycle. | Lead PM |
| Current Phase | User Exposure | Indicates who can currently see or use the change. | Lead PM / Release Owner |
| Current Phase | Progress % | Provides a directional completion indicator. | Lead PM / delivery owner |
| Current Phase | Status | Summarizes health using a standard status scale. | Lead PM |
| Current Phase | Confidence of Owner (1-10) | Captures the accountable owner's confidence in the current plan and outcome. | Owner |
| Current Phase | IT Risk Level | Indicates technical or delivery risk. | IT Product Management / TPM |
| Current Phase | Primary Risk | Names the most important current risk. | Lead PM, with phase owner input |
| Next Major Gate | Next Major Gate | Identifies the next lifecycle checkpoint or decision point. | Lead PM |
| Next Major Gate | Next Gate ETA | Gives the expected timing for the next gate. | Lead PM / delivery owner |
| Rollout | Primary Target | Names the first or primary rollout audience. | Lead PM / PMO / Release Owner |

## Recommended Status Scale

| Status | Meaning |
| --- | --- |
| Green | On track. No material action or decision needed. |
| Yellow | At risk. Action is underway, or a decision may be needed soon. |
| Red | Off track or blocked. Leadership action, decision, or tradeoff is needed. |
| Gray | Not started, paused, or waiting for triage. |

## Confidence Guidance

Confidence is the owner's honest assessment of whether the project will meet its intended outcome, timeline, readiness, and quality expectations.

| Score | Meaning |
| --- | --- |
| 9-10 | High confidence. Risks are known and controlled. |
| 7-8 | Good confidence. Some watch items exist but are manageable. |
| 5-6 | Moderate confidence. Meaningful uncertainty, dependency, or risk exists. |
| 3-4 | Low confidence. Major risk, blocker, or unresolved decision exists. |
| 1-2 | Very low confidence. Current plan is unlikely to hold without intervention. |

## Communication Use

Use this dashboard for:

- Planned status updates.
- Weekly digest.
- Executive reviews.
- Unexpected status changes.
- Gate readiness conversations.
- Risk escalation.

The dashboard should not replace detailed project artifacts. It should point leaders to the current state and make action needs obvious.
