# Change Proposal 0004: Communication Triggers and Executive Dashboard

## Problem

The communication model needs a practical trigger framework and a standard executive dashboard for planned status updates and weekly digest communication.

## Proposal

Add:

- Communication trigger categories.
- Core trigger list.
- Payload rule for `What`, `So What`, and `What's Next`.
- Executive dashboard field definitions.
- Executive dashboard CSV template.

## Expected Impact

- Stakeholder communication becomes more predictable and action-oriented.
- Executive updates focus on phase, status, confidence, risk, next gate, and rollout target.
- Weekly digest and planned project updates can use the same source fields.

## Risks

- Progress percentage may create false precision if not defined consistently.
- Confidence score requires honesty from accountable owners or it becomes decorative.
- Dashboard fields must stay concise or the executive view will become hard to scan.

## Adoption Notes

Use this dashboard as the executive surface, not as the full project plan. Detailed requirements, risks, decisions, and release artifacts should remain in their source documents.
